## Practical -

1. Install VMware and run differnt VMs (Linux, Windows), try to load VM image with install software on it. Install Docker, run 3 container of your choosing, load files into one of them from your desktop, make them talk to each other from the same network.
2. Install 1 Linux VM and install K3S. On the K3S cluster, install one app found on the internet with "kubectl apply", one app with "kustomize", one app with "helm".
3. Install two apps with "kubectl apply" having written the manifest yourself including the following objects to configure and allow the apps to communicate: 
	- configMap
	- service
	- deployment
	Make the apps communicate via Http, find apps already existing for testing purpose, one that can serve as an https server and one that can send http requests
